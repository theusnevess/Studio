# Padroes de Desenvolvimento

## Convencao de branches

- `main`
- `develop`
- `feature/<nome>`
- `fix/<nome>`
- `docs/<nome>`

## Convencao de commits

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `chore:`

## Organizacao de pastas

- `backend/`: API, configuracoes, seguranca, persistencia e servicos
- `frontend/`: interface web, rotas, layouts, componentes e servicos de consumo
- `docs/`: documentacao funcional e arquitetural

## Principios de codigo

- Clareza de nomes e responsabilidades
- Separacao simples entre camadas
- Evolucao incremental
- Evitar overengineering
- Manter o sistema executavel localmente
- Respeitar o escopo academico do projeto
